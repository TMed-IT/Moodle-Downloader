# Moodle-Downloader

Moodleからファイルを一括ダウンロードしGoodnoteへ読み込ませるためのブックマークレット・iosショートカット

## 概要

```
Moodleのコースページを開く
        ↓
ブックマークレットを実行
        ↓
ファイルを選択してJSON(ファイル情報)をコピー
        ↓
iOSショートカットを実行
        ↓
ファイルが順番にダウンロードされ、Zip化
        ↓
GoodNotesに読み込む
```
※ブックマークレットとはwebブラウザのブックマークからJavaScriptを実行できる機能

## ファイル構成

| ファイル | 説明 |
|---------|------|
| `bookmarklet.js` | ブックマークレット本体（整形済みソース） |
| `bookmarklet.txt` | Safariに登録するための1行版 |
| `MoodleDownloader.shortcut` | iOSショートカット |

---

## セットアップ

### 1. ブックマークレットをSafariに登録する

1. Safariで任意のページを開き、共有ボタン（□↑）→「ブックマークを追加」
2. 左上サイドバーを開き、ブックマーク一覧から追加したものを **長押し** →「編集」
3. 上段タイトルを **「Moodle収集」** などに変更
4. 下段URLを **全選択して削除** し、`bookmarklet.txt` の中身をまるごとペースト
5. 「完了」をタップ

> URL が `javascript:(async()=>{...})();` という形式になっていれば正しく登録されています。

### 2. iOSショートカットを読み込む
1. `MoodleDownloader.shortcut`をご自身のショートカットアプリに追加

## 使い方(デモ動画も参照)

### STEP 1 — ブックマークレットを実行する

1. SafariでMoodleのコースページを開く
2. 左上スライドバーを開き、ブックマーク一覧から「Moodle収集」を開く
3. 画面右側にパネルが表示される

### STEP 2 — ダウンロードするファイルを選択する

```
┌─────────────────────────────────┐
│ Moodle ファイル収集    全選択 ×  │
├─────────────────────────────────┤
│ ∨ 第1回：イントロダクション  ✓  │
│     ☑ PDF  授業概要とシラバス    │
│     ☑ PDF  第1回講義スライド     │
│ ∨ 第2回：基礎理論            ✓ │
│     ☐ PDF  基礎理論テキスト      │
│     ☐ PPT  第2回講義スライド     │
├─────────────────────────────────┤
│ 2 / 4 件選択                    │
│  [ JSONをコピー（2件）]          │
└─────────────────────────────────┘ 
```
選択が終わったら 一番下の **「JSONをコピー」** をタップ。ボタンが青くなって閉じればコピー成功。

| 操作 | 動作 |
|------|------|
| セクション行をタップ | そのセクションを全選択／全解除 |
| `∨` ボタンをタップ | セクションを折りたたむ／展開する |
| ファイル行をタップ | 個別に選択／解除 |
| 「全選択」ボタン | 全ファイルを選択（もう一度で全解除） |
| 右上ｘをタップ | パネルを閉じる |


### STEP 3 — ショートカットを実行する

1. 画面は変えずにSafari右上の共有ボタン(□↑)をタップ
2. 右下のもっと見るを押し、下にスクロールMoodleDownloaderを探す
3. MoodleDownloaderをタップしてダウンロード開始！
> 実行時に権限の許可のポップアップがでるので、承認してください

### STEP 4 — GoodNotesに読み込む

1. 生成されたZipファイルをGoodnoteへ共有(□↑)
2. 複数ファイルを一括で読み込めます！

## ファイル名のカスタマイズ
ショートカットを編集することで保存するファイル名をカスタムすることができます。  
詳しくはショートカット中の後半にあるコメントを参照してください


## JSONの構造

ブックマークレットがコピーするJSONの構造です。

```json
[
  {
    "section": "第1回：イントロダクション",
    "name": "授業概要とシラバス.pdf",
    "url": "https://..."
  },
  {
    "section": "第2回：基礎理論",
    "name": "基礎理論テキスト.pdf",
    "url": "https://..."
  }
]
```

## 注意事項
- PDF以外のファイルはPDFに変換しzip化しています。背景やレイアウトなどが元ファイルと異なる場合があります
- 多数のファイルを一度にダウンロードすると処理が止まることがあります。その際は複数回に分けてダウンロードしてください
- 動作確認は東邦大学MoodleのHTML構造をベースにしています。他大学のMoodleでも動く可能性はありますが、保証はありません
- ブックマークレットはすでにブラウザに表示されているDOMを読み取るだけで、サーバーへの追加リクエストは行いません
- 取得した情報は外部に送信されず、クリップボードにのみ保存されます
- 自己責任でお使いください
